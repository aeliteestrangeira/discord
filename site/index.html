WINDOWS DESKTOP

O mesmo site, agora em aplicativo desktop.

Electron abre o backend Flask local em HTTPS, preserva os dados da instalação e recebe novas versões por GitHub Releases.

01

Mesmo aplicativo

O desktop não recria as telas. Ele inicia o backend local e carrega a aplicação já existente.

02

Atualizações

O aplicativo verifica GitHub Releases sem polling agressivo e baixa uma versão nova quando disponível.

03

Estado persistente

Dados locais, chaves e configuração privada ficam fora do diretório substituído pelo instalador.

MODELO DE DISTRIBUIÇÃO

O GitHub entrega o software, não suas credenciais.

O repositório, o GitHub Pages e os Releases são públicos. Arquivos privados como SUPABASE_PRIVILEGED.env e o diretório instance/ permanecem somente na máquina do usuário.
