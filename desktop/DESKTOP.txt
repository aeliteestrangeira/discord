Desktop 4.2.0
=============

SOURCE/ALPHA MODE
- DESKTOP_START.bat continua abrindo o mesmo site Flask dentro do Electron.
- Python/.venv, instance e configuracao podem permanecer no projeto local.

INSTALLED MODE
- electron-builder/NSIS cria o instalador Windows x64.
- PyInstaller cria discord-backend.exe e discord-tls.exe no GitHub Actions.
- Dados persistentes: %LOCALAPPDATA%\AEliteEstrangeira\DiscordDesktop\
- A instalacao/atualizacao nao substitui instance/, config privada ou perfil Electron.
- Se a configuracao privada persistente estiver ausente, o app permite selecionar explicitamente SUPABASE_PRIVILEGED.env.

UPDATE
- electron-updater usa GitHub Releases publico.
- Sem setInterval/polling periodico.
- Check automatico no startup respeita intervalo minimo de 6 horas.
- Quando uma versao e encontrada, o pacote e baixado e o usuario escolhe quando reiniciar.

GITHUB PAGES
- site/ e somente pagina publica de distribuicao/documentacao.
- Nenhum login/senha e coletado no github.io.
- Workflow: .github/workflows/pages.yml

RELEASE
- Crie uma tag que corresponda exatamente ao package.json, por exemplo v4.2.0.
- O workflow .github/workflows/release-desktop.yml gera o NSIS .exe e publica a GitHub Release.
