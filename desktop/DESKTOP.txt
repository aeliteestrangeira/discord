# Desktop Electron — fase 1

Esta camada abre **o mesmo site Flask existente** dentro de uma `BrowserWindow` Electron. Ela não substitui HTML, CSS, autenticação, Supabase, hCaptcha, voz ou as rotas Flask.

## Executar no Windows

1. Instale Node.js LTS.
2. Execute `DESKTOP_START.bat` na raiz.
3. Na primeira execução, o script instala Electron e, se necessário, o ambiente Python existente.
4. A preparação do hostname `discord` pode solicitar UAC uma única vez.
5. O Electron prepara HTTPS local, inicia Flask sem abrir navegador externo, valida `/api/desktop/health` e só então mostra a aplicação.

## Baseline de segurança

- `nodeIntegration: false`.
- `contextIsolation: true`.
- `sandbox: true`.
- `webSecurity: true`.
- `<webview>` desabilitado.
- Nova janela bloqueada; somente origens HTTPS explicitamente permitidas podem abrir no navegador do sistema.
- Permissões em default-deny; somente microfone (`media: audio`) é permitido para `https://discord:8000`.
- Erro de certificado TLS não é ignorado: a CA local precisa estar instalada corretamente.
- O backend continua vinculado a `127.0.0.1` e o Host permitido continua sendo `discord`.

## Escopo desta fase

Esta é a primeira integração desktop. Ainda não é o instalador público final e ainda não contém o pipeline de GitHub Releases/auto-update. A próxima fase deve empacotar o runtime Python/backend fora do ASAR, preservar `instance/` em diretório persistente e gerar o instalador Windows assinado.
